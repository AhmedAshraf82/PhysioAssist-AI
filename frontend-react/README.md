# PhysioAssist React Frontend

Production-style React frontend replacing Streamlit POC.

## Features
- Login page (demo credentials)
- Top search bar with injury search
- Data ingestion action (top-left)
- Floating chatbot icon (bottom-left)
- Dedicated chat page with session list + new chat

## Run
1. Copy `.env.example` to `.env`
2. Install deps: `npm install`
3. Start dev server: `npm run dev`

Backend default URL is `http://localhost:8002`.
